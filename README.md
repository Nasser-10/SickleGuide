# SickleGuide

SickleGuide is an evidence-grounded clinical AI system for
Sickle Cell Disease in children and adolescents.

## Architecture

Data Sources
    ↓
Document Ingestion
    ↓
Preprocessing
    ↓
Markdown Conversion
    ↓
Section-Aware Chunking
    ↓
Metadata
    ↓
BGE-M3 + BM25 + Graph
    ↓
Hybrid Search (RRF)
    ↓
Reranker
    ↓
Graph Retrieval
    ↓
Evidence Fusion
    ↓
Grounded LLM
    ↓
Claim-Evidence Check
    ↓
Citation
    ↓
Final Answer
    ↓
FastAPI + React
    ↓
Docker
